# Security Policy

## Supported Versions

This starter kit is maintained as a learning project. Use the latest commit on the main branch.

## Reporting A Vulnerability

If you find a security issue in this repository, please open a private security advisory if the repository is hosted on GitHub. If private advisories are not available, contact the maintainer without posting exploit details publicly.

Please include:

- A clear description of the issue.
- Steps to reproduce.
- Impact and affected files.
- Suggested fix, if known.

## Scope

In scope:

- Bugs in the `repo-security-checker` script.
- Incorrect security guidance in the documentation.
- Unsafe examples that could encourage misuse.

Out of scope:

- Testing systems that you do not own or do not have permission to assess.
- Reports about third-party tools linked from the documentation.
