# Cybersecurity Tools

This list focuses on tools that are useful for learning, defensive work, and authorized security testing.

## Repository And Supply Chain

| Tool | Use |
|---|---|
| Gitleaks | Finds hardcoded secrets in repositories and files. |
| TruffleHog | Finds, verifies, and analyzes leaked credentials. |
| Trivy | Scans containers, repositories, Kubernetes, IaC, SBOM, vulnerabilities, and secrets. |
| OSV-Scanner | Scans dependencies using the OSV vulnerability database. |
| OpenSSF Scorecard | Checks open source project security practices. |
| Dependabot | Helps keep dependencies updated in GitHub repositories. |
| CodeQL | Static analysis for finding security issues in code. |

## Web And Application Security

| Tool | Use |
|---|---|
| OWASP ZAP | Web app security scanner and proxy. |
| Burp Suite Community | Intercepting proxy for learning and manual web testing. |
| Nuclei | Template-based vulnerability scanner for authorized targets. |
| mitmproxy | Programmable intercepting HTTP/TLS proxy. |

## Monitoring, Detection, And Response

| Tool | Use |
|---|---|
| Wazuh | Open source XDR and SIEM platform. |
| Security Onion | Threat hunting, network security monitoring, and log management platform. |
| Zeek | Network security monitoring framework. |
| Suricata | IDS, IPS, and network security monitoring engine. |
| Sigma | Generic detection rule format for SIEM systems. |
| Velociraptor | Endpoint visibility, DFIR, and incident response. |

## Threat Intelligence

| Tool | Use |
|---|---|
| MITRE ATT&CK | Knowledge base of adversary tactics and techniques. |
| CISA KEV Catalog | Known exploited vulnerabilities that should be prioritized. |
| MISP | Threat intelligence sharing platform. |
| OpenCTI | Cyber threat intelligence management platform. |
| TheHive | Security incident response and case management platform. |

## Reverse Engineering And Malware Analysis

Use these only in isolated lab environments.

| Tool | Use |
|---|---|

| radare2 | Reverse engineering framework and command-line toolset. |
| Ghidra | Software reverse engineering suite. |
| capa | Identifies capabilities in executable files. |
| FLARE VM | Windows reverse engineering environment setup. |
