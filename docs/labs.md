# Safe Practice Labs

Use legal, intentional training environments. Do not scan or test systems without permission.

## Web Security

| Lab | Best For |
|---|---|

| OWASP Juice Shop | Vulnerable web app practice in a controlled environment. |
| OWASP WebGoat | Guided web security lessons. |

## How To Write Lab Notes

Use this template:

```md
# Lab Name

## Topic

What security concept does this lab teach?

## What I Observed

What happened during the lab?

## Root Cause

Why was the system vulnerable?

## Defensive Fix

How should this be prevented or detected?

## References

List the official docs or learning pages used.
```
